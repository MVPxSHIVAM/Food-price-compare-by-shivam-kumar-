🍽️ Buy.Hatke — Food Price Comparison Website
A simple and visually appealing web app that allows users to compare the prices of a food item across different online delivery platforms like Zomato, Swiggy, and UberEats.
It highlights the best deal and gives a direct link to order.

🚀 Features
🔍 Search any food item

💸 Compare prices between platforms

🏆 Automatically shows the cheapest option

🔗 Includes a direct external link to the cheapest platform

🎨 Beautiful gradient UI with animations

📱 Fully responsive and beginner-friendly code

⚡ 100% client-side (no backend required)

🛠️ Technologies Used
HTML5

CSS3 (Gradients, Cards, Animations)

JavaScript (comparison logic)
